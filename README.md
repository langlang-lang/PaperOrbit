# PaperOrbit

> 先看笔记，再回到证据。

PaperOrbit 是一款“笔记在先”的本地文献管理工具。PDF 仍然保存在你自己的文件夹中，软件只建立索引，不接管文件。

## 下载

[进入最新版本下载页](https://github.com/langlang-lang/PaperOrbit/releases/latest)

- macOS（Apple Silicon）：推荐下载 `PaperOrbit-macOS-0.3.5-arm64.dmg`
- Windows 10/11（x64）：推荐下载 `PaperOrbit-Windows-0.3.5-x64.exe`
- Windows 免安装版：下载 `PaperOrbit-Windows-0.3.5-Portable-x64.exe`

## 核心体验

- 笔记列表和球形滚动模式，让笔记成为阅读入口
- 点击笔记时，动画会定位并拉出对应 PDF，直接回到原文位置
- 在 PDF 中划线、记录笔记，并可点击高亮再次查看笔记
- 按文献分别导出 Markdown 笔记
- PDF 按本地文件夹分类，支持重命名索引和打开文件原位置
- 可移除文献索引，不会删除本地 PDF 文件
- 支持搜索；也可选填自己的 AI API 来增强笔记检索

## 数据说明

- 安装包不包含开发者的文献索引、笔记或 PDF
- 你的索引和笔记只保存在自己的电脑中
- 移除索引不会删除本地文件
